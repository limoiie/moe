# Issues

One Markdown file per issue, `MOE-NNNN-slug.md`. All operations — create, read, list, comment,
label, close — are plain file edits; the conventions live in
[`../agents/issue-tracker.md`](../agents/issue-tracker.md).

Linear-era issues (workspace `iie4limo`, team `IIE4AD`, project Moe) stay in the
[Linear workspace](https://linear.app/iie4limo) as the historical record; new work is filed here.
