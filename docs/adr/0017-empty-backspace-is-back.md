# 空输入的 Backspace 等于 Back

命令盘是 keyboard-first：回退靠 `Esc`。但手指在输入栏上时，回头删字删到最后一下，自然就落在 `Backspace` 上；
此时再按一次 `Esc` 需要把手挪到左上角。VS Code 的 Quick Open、Slack 的返回、Finder 的向上一层，都统一成
「输入为空时 Backspace 当返回用」——而且这个规则不需要用户记，删空之后本来就没有东西可删。

## 决定

- **输入非空**：什么都不做（浏览器默认删字/删选区）。判断只看输入是否为空，有选区也算非空。
- **输入为空**：`preventDefault()`，然后走**与 `Esc` 完全相同的那个函数**（面板 `back()`、侧栏 `back()`），
  所以两个键位的分层回退永远一致，不会各写一套：
  - 面板：停止生成 → 收起动作面板 → 收起详情预览 → 回到命令层 → 清空输入 → 关闭面板；
  - 侧栏：收起历史卡 → 收起操作菜单 → 停止生成 → 收起窗口。
- **所有文本输入一致**：面板 Input Bar、侧栏 composer、历史卡搜索框、附件路径框（空时退出一层/取消该模式）。
  各浮层自己的输入框在 keydown 里 `stopPropagation`，避免与全局规则双重触发。

## 代价

- 根层的空 Backspace 会关掉面板（与 Esc 同代价），这是有意的：那就是 Esc 的语义。
- 输入非空时 Backspace 仍是纯删字，删空那一瞬间**不会**连带触发回退（下一次按键才是回退），避免「删着删着面板突然关了」。
