# UI 图标用 Lucide：契约只存语义名

面板与侧栏需要一套统一的图标，用来标记命令、结果项与界面动作。

## 选型

- **Lucide**（选中）：MIT；统一的 24px 网格 + 2px 描边 + 圆角端点，线性风格与现有 zinc 深色体系一致；ESM 按需 import 可 tree-shake（实测只引入用到的图标，产物 +27KB gzip）；有 `createElement` 直接生成 SVG 的 API，适合我们「无框架、TS 动态渲染」的视图层。
- **Remix Icon**（未选）：图标更多（2800+），但以字体/填充风格为主、线面混用，描边粗细与端点不统一；在深色小尺寸场景下与我们的界面语言不如 Lucide 一致。

## 契约

`CommandMeta.icon` 与 `Item.icon` 都是可选的**语义名**（字符串），平台与扩展不知道具体图形；视图层负责「语义名 → 图形」的映射，未知名回退到默认圆圈。这样：

- 扩展与 UI 解耦（换图标集只改 `ui/src/icons.ts` 一张表）；
- 新增命令不会因为没给图标而破坏布局（永远占一个 16px 槽位）。

## 代价

- 图标名没有类型约束，拼错会静默回退（有 `hasIcon` 可用于需要区分「扩展给了图标」的分支）。
- 图标集升级（比如 Lucide 改名）需要同步映射表。
